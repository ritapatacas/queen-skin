# Queen Skin

Personalized skincare routine reference app. **Live:** https://ritapatacas.github.io/queen-skin

Built with React 19 · TypeScript · Tailwind CSS v4 · Framer Motion · Vite

---

## What it does

- **Weekly schedule** — routine per day (Treatment / Peeling / Recovery / Blackheads)
- **Product grid** — hover to expand product image inline; state machine handles layout
- **Product detail** — application steps, timing, face zone diagram, tips, incompatibilities
- **15 products** across 8 categories from La Roche-Posay, Vichy, Bioderma, Galénic, Caudalie, CeraVe, Blooming Skin

## Development

```bash
pnpm install
pnpm dev
pnpm test        # Vitest
pnpm build       # → dist/
pnpm deploy      # build + push to gh-pages
```
